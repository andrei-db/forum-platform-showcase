# Modern Community Forum Platform

A full-stack forum platform with a custom admin control panel, forum permissions, analytics dashboard and modern community management tools.

## Live Demo

Frontend: [Live Website](https://forum-frontend-three.vercel.app/)  
Backend API: [API](https://forum-backend-5r3y.onrender.com/)

## Repositories

Frontend: [forum-frontend](https://github.com/andrei-db/forum-frontend)  
Backend: [forum-backend](https://github.com/andrei-db/forum-backend)

## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- Recharts
- Lucide React

### Backend
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- JWT Authentication

## Features

- User authentication
- Forum categories and forums
- Topics and replies
- First post / last post architecture
- Group system
- Forum permissions
- Staff-only admin panel
- Admin dashboard with charts
- Member management
- Group management
- Forum settings
- Maintenance mode
- Responsive UI
